🔬 Motivation

Existing LLM benchmarks lack statistical rigor, suffer from non-reproducible sampling, and use opaque LLM-as-judge grading — making fair cross-model comparison unreliable.

We present Modular LLM Scorer: a modular, deterministic pipeline evaluating LLMs across four cognitive domains using rule-based graders, 95% Wilson score confidence intervals, and sandboxed code execution — with full prompt and token logging for reproducibility.

Every result is fully auditable from prompt text to final score. No LLM judge is used anywhere.

✅  No LLM-as-Judge · Pure Rule-Based Evaluation

📐 Statistical Methods
① Wilson Score — 95% Confidence Interval
CI₉₅ = ( p̂ + z²/2n  ±  z √(p̂(1−p̂)/n + z²/4n²) ) / ( 1 + z²/n )
where  p̂ = accuracy  ·  n = sample count  ·  z = 1.96 (95%)
Applied per domain, difficulty tier & dataset · Handles 0% and 100% correctly
② McNemar's Test — Paired Model Comparison
χ² = ( |b − c| − 1 )² / ( b + c )
where  b = M1✓ M2✗  ·  c = M2✓ M1✗  ·  α = 0.05 · requires ≥ 25 disagreements
p < 0.05 → statistically significant difference between models
③ Weighted Final Score
score = Σ domain_accuracy[d] × domain_weight[d]
for d ∈ { math·0.25, logic·0.25, knowledge·0.35, code·0.15 }
